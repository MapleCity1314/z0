# Z0 应用 UI 设计风格指南

## 概述

Z0 是一个现代化的 AI 聊天应用，采用了简洁、专业的设计风格，支持明暗主题切换，注重用户体验和视觉一致性。

## 设计理念

- **极简主义**：界面简洁，减少视觉干扰，突出核心功能
- **现代化**：使用现代设计语言，圆角、阴影、渐变等元素的合理运用
- **专业感**：深色主题为主，营造专业开发环境的氛围
- **响应式**：完美适配桌面端和移动端设备

## 配色方案

### 主色调系统

应用使用基于 OKLCH 色彩空间的现代配色系统，确保色彩的一致性和可访问性。

#### 明亮主题 (Light Theme)
- **背景色**: `oklch(1 0 0)` - 纯白色
- **前景色**: `oklch(0.141 0.005 285.823)` - 深灰色文字
- **主色**: `oklch(0.21 0.006 285.885)` - 深蓝灰色
- **次要色**: `oklch(0.967 0.001 286.375)` - 浅灰色
- **边框色**: `oklch(0.92 0.004 286.32)` - 淡灰色边框

#### 深色主题 (Dark Theme)
- **背景色**: `oklch(0.141 0.005 285.823)` - 深灰黑色
- **前景色**: `oklch(0.985 0 0)` - 近白色文字
- **主色**: `oklch(0.92 0.004 286.32)` - 浅灰色
- **次要色**: `oklch(0.274 0.006 286.033)` - 中灰色
- **边框色**: `oklch(1 0 0 / 10%)` - 半透明白色边框

#### 功能性颜色
- **成功色**: 绿色系，用于成功状态提示
- **警告色**: 黄色系，用于警告信息
- **错误色**: `oklch(0.577 0.245 27.325)` (明亮) / `oklch(0.704 0.191 22.216)` (深色) - 红色系
- **图表色**: 5种预定义颜色，用于数据可视化

### 侧边栏配色
- **侧边栏背景**: 明亮主题为白色，深色主题为深灰色
- **侧边栏主色**: 深色主题中使用紫色调 `oklch(0.488 0.243 264.376)`
- **侧边栏强调色**: 与主题保持一致的灰色系

## 字体系统

### 字体族
- **无衬线字体**: Geist Sans - 用于界面文字，现代简洁
- **等宽字体**: Fira Code - 用于代码显示，支持连字符
- **后备字体**: 系统默认字体栈

### 字体大小层级
- **小号文字**: `text-sm` (14px) - 用于辅助信息
- **正文**: `text-base` (16px) - 主要内容文字
- **标题**: `font-semibold` - 卡片标题等重要信息

## 组件设计规范

### 按钮 (Button)
- **圆角**: `rounded-md` (6px)
- **高度**: 默认 36px，小号 32px，大号 40px
- **内边距**: 水平 16px，垂直 8px
- **变体**:
  - `default`: 主色背景，白色文字
  - `outline`: 透明背景，边框样式
  - `ghost`: 悬停时显示背景
  - `destructive`: 红色背景，用于危险操作

### 卡片 (Card)
- **圆角**: `rounded-xl` (12px)
- **阴影**: `shadow-sm` - 轻微阴影
- **内边距**: 24px
- **背景**: 卡片背景色，与主背景略有区别

### 输入框 (Input)
- **圆角**: `rounded-md` (6px)
- **边框**: 1px 实线边框
- **焦点状态**: 3px 环形阴影，主色调
- **错误状态**: 红色边框和阴影

## 布局系统

### 间距规范
- **基础间距单位**: 4px (Tailwind 的 spacing scale)
- **组件间距**: 通常使用 16px (gap-4) 或 24px (gap-6)
- **页面边距**: 桌面端 24px，移动端 16px

### 响应式断点
- **移动端**: < 768px
- **桌面端**: ≥ 768px
- **大屏**: ≥ 1024px

### 容器宽度
- **最大宽度**: 768px (max-w-3xl) - 聊天界面主容器
- **居中对齐**: `mx-auto` - 水平居中

## 交互设计

### 动画效果
- **过渡时间**: 150ms-300ms
- **缓动函数**: `ease-in-out`, `ease-out`
- **页面切换**: 淡入淡出效果
- **组件状态**: 平滑的颜色和尺寸变化

### 悬停状态
- **按钮**: 背景色变深 10%
- **链接**: 下划线显示
- **卡片**: 轻微阴影增强

### 焦点状态
- **可访问性**: 明显的焦点环
- **颜色**: 主色调的半透明版本
- **宽度**: 3px

## 滚动条样式

### 自定义滚动条
- **宽度**: 6px
- **轨道**: 透明背景
- **滑块**: 半透明灰色，圆角
- **悬停**: 滑块颜色加深

## 品牌元素

### Logo 设计
- **图形**: "Z0" 字母组合
- **风格**: 几何形状，现代简约
- **颜色**: 当前文字颜色 (currentColor)
- **尺寸**: 默认 32px，可缩放

### 品牌色彩
- **主品牌色**: 深蓝灰色系
- **辅助色**: 紫色调 (侧边栏强调)

## 主题切换

### 实现方式
- 使用 `next-themes` 库
- 支持系统主题检测
- 类名切换方式 (`class` attribute)
- 无过渡动画，避免闪烁

### 切换按钮
- **位置**: 通常在用户菜单或设置区域
- **图标**: 太阳/月亮图标
- **样式**: Ghost 按钮样式

## 可访问性

### 色彩对比
- 所有文字与背景的对比度符合 WCAG 2.1 AA 标准
- 使用 OKLCH 色彩空间确保感知均匀性

### 键盘导航
- 所有交互元素支持键盘访问
- 明显的焦点指示器
- 合理的 Tab 顺序

### 屏幕阅读器
- 语义化 HTML 结构
- 适当的 ARIA 标签
- 隐藏装饰性元素

## 开发规范

### CSS 架构
- **Tailwind CSS**: 原子化 CSS 框架
- **CSS 变量**: 用于主题色彩管理
- **组件化**: 可复用的 UI 组件库

### 命名约定
- **组件**: PascalCase (如 `ChatInput`)
- **CSS 类**: kebab-case (如 `chat-input`)
- **变量**: camelCase (如 `selectedModel`)

### 文件组织
- `components/ui/`: 基础 UI 组件
- `components/chat/`: 聊天相关组件
- `app/globals.css`: 全局样式和主题定义

## 总结

Z0 应用的 UI 设计风格体现了现代 Web 应用的最佳实践，通过精心设计的配色方案、一致的组件规范和良好的用户体验，为用户提供了专业、高效的 AI 聊天界面。设计系统的模块化和可扩展性也为未来的功能扩展奠定了良好的基础。
